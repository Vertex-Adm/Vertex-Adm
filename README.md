# 👨‍💻 Vertex Apps Studio

**`Desenvolvedor de Apps | Web | Sistemas`**

A **Vertex Apps Studio** é uma marca focada no desenvolvimento de aplicações, sistemas web e soluções digitais modernas.  
Criamos projetos tecnológicos com foco em desempenho, funcionalidade, organização e experiência do utilizador.

Atualmente, os projetos são desenvolvidos por **José Silva**, estudante e profissional da área de **Tecnologias de Informação e Programação**, com foco em desenvolvimento de aplicações, sistemas web e soluções digitais.

📍 Porto, Portugal
